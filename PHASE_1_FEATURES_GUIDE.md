# Phase 1 Features - Quick Reference Guide

## 🎯 **How to Use the New Features**

---

## 1. **Offline Mode** 📴

### **What It Does**:
- Automatically saves all data locally when offline
- Syncs changes when connection is restored
- Shows sync status in the UI

### **How to Use**:
1. **No setup required** - works automatically!
2. **Monitor Status**: Check the offline indicator at the top of the app
3. **Manual Sync**: Pull down to refresh any list view
4. **View Details**: Tap the info button on the offline indicator

### **Offline Indicator States**:
- 🟢 **"Online"** - Connected, all changes syncing
- 🟡 **"Syncing..."** - Connection restored, syncing pending changes
- 🔴 **"Offline Mode"** - No connection, saving locally
- **Badge Number** - Shows pending sync operations count

---

## 2. **Google Calendar Integration** 📅

### **What It Does**:
- Syncs team events with your Google Calendar
- Two-way sync (create events in either place)
- Manages attendees and locations

### **How to Use**:

#### **Connect Google Calendar**:
1. Go to **Settings** → **Calendar Integration**
2. Tap **"Connect Google Calendar"**
3. Sign in with your Google account
4. Grant calendar permissions

#### **Sync Events**:
- **Automatic**: Events sync every time you open the view
- **Manual**: Tap the sync button to sync immediately

#### **Manage Events**:
- Create events in the FTC Hub - they appear in Google Calendar
- Create events in Google Calendar - they appear in the Hub
- Edit or delete in either place

---

## 3. **Export & Backup** 💾

### **What It Does**:
- Export data to CSV or PDF
- Create complete backups
- Share exported files

### **How to Use**:

#### **Export to CSV**:
1. Go to **Settings** → **Export Options**
2. Select data type (Inventory, Scouting, Team, Events)
3. Tap **"Export to CSV"**
4. Choose where to save or share

#### **Generate PDF Report**:
1. Go to **Settings** → **Export Options**
2. Tap **"Generate Team Report"**
3. PDF includes:
   - Team information
   - Member roster
   - Upcoming events
   - Inventory summary
   - Scouting statistics

#### **Create Backup**:
1. Go to **Settings** → **Backup Options**
2. Tap **"Create Backup"**
3. Save the backup file securely
4. **Restore**: Tap **"Restore from Backup"** and select file

---

## 4. **Push Notifications** 🔔

### **What It Does**:
- Alerts for upcoming events and matches
- Low stock and out of stock alerts
- Task deadline reminders
- Grant deadline notifications

### **How to Use**:

#### **Enable Notifications**:
1. When prompted, tap **"Allow"** for notifications
2. Or go to **Settings** → **Notification Settings**
3. Tap **"Enable Notifications"**

#### **Customize Notifications**:
1. Go to **Settings** → **Notification Settings**
2. Toggle categories on/off:
   - Event Reminders
   - Match Reminders
   - Task Reminders
   - Inventory Alerts
3. Set reminder times:
   - Event: X minutes before
   - Match: X minutes before
   - Task: X hours before

#### **Notification Actions**:
When you receive a notification, you can:
- **Events**: View Event or Snooze 15 min
- **Matches**: View Match or Snooze 5 min
- **Inventory**: View Item or Order Now
- **Tasks**: View Task or Mark Complete

---

## 5. **Parts Library** 🔧

### **What It Does**:
- Browse 40+ pre-loaded FTC parts
- Quickly add parts to inventory
- Search and filter by category/manufacturer

### **How to Use**:

#### **Browse Parts**:
1. Go to **Inventory** → tap **"+ Add Item"**
2. Tap **"Browse Parts Library"**
3. Browse by category or use search

#### **Filter Parts**:
- Tap the filter icon (three lines)
- Select category (Motors, Sensors, Wheels, etc.)
- Select manufacturer (REV Robotics or TETRIX)
- Or use the quick filter menu

#### **Add to Inventory**:
1. Find the part you want
2. Tap on it
3. Enter:
   - Initial quantity
   - Location (optional)
4. Tap **"Add"**
5. Part is added with:
   - Pre-filled name, SKU, manufacturer
   - Default low stock threshold
   - Pricing (if available)
   - Full specifications

#### **Search Parts**:
- Use the search bar to find by:
  - Part name
  - SKU
  - Category
  - Manufacturer

## 🚨 **Troubleshooting**

### **Offline Sync Not Working**:
1. Check internet connection
2. Pull to refresh
3. Check sync status in offline indicator
4. Try manual sync from settings

### **Google Calendar Not Connecting**:
1. Make sure you granted calendar permission
2. Check Google account is signed in
3. Try disconnecting and reconnecting
4. Check internet connection

### **Notifications Not Appearing**:
1. Check notification permissions in iOS Settings
2. Enable notifications in app Settings
3. Make sure event/match is in the future
4. Check reminder time settings

### **Parts Library Not Loading**:
1. Make sure JSON files are included in app
2. Restart the app
3. Check for any error messages

## 💡 **Best Practices**

1. **Regular Backups**:
   - Create backups weekly during season
   - Before and after competitions
   - Store backups in multiple locations

2. **Notification Management**:
   - Set match reminders for 10-15 minutes
   - Set event reminders for 15-30 minutes
   - Enable inventory alerts to never run out

3. **Parts Management**:
   - Add common parts from library at start of season
   - Keep quantities updated
   - Set appropriate low stock thresholds

4. **Calendar Integration**:
   - Connect team's Google Calendar
   - Share calendar with all team members
   - Keep event details up to date
